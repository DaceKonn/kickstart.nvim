# What is this

This is a personal Nvim configuration that I try to configure for myself.

# What is it based on

This is based on few sources, namely:

* NVIM Kickstart : [nvim-lua/kickstart.nvim](https://github.com/nvim-lua/kickstart.nvim)
* NeoVim Configuration For Fullstack Java Developers : [unknownkoder/Java-FullStack-NeoVim-Configuration](https://github.com/unknownkoder/Java-FullStack-NeoVim-Configuration)

## Note on the origins

I firstly used Kickstart as a jumping point, which serves as a great starter for a configuration. But I had issues with adding new plugins, configs and especially setting up Java.

So I dumped everything and shamelessly copied all the "NeoCim ... For Fullstack Java Developers" and started from there. I did tweaks to make it work both on windows nad linux (hopefully),
and I ported some things from Kickstart. Plus added some of my own changes.

This isn't a finished nor a stable repository.
